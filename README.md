# 国試ドリル ― 重要問題 & 禁忌選択肢

医師国家試験の頻出テーマと、**「選んではいけない選択肢（禁忌選択肢）」** を集中的に鍛えるための練習Webアプリです。禁忌肢は本番の国試で1つでも選ぶと不合格に直結するため、本アプリでは通常の正誤とは別枠で警告・集計します。

## 特長

- **禁忌選択肢の特別扱い** ― 禁忌肢を選ぶと本番同様に赤く警告し、「禁忌ヒット数」を正誤とは別に集計。解答後は選ばなかった禁忌肢も薄く提示して学べます。
- **科目・重要度フィルタ** ― 科目（循環器・救急・産婦人科 …）や重要度（必修級★★★／頻出★★／標準★）で出題を絞り込み。
- **3つのモード**
  - 練習：1問ごとに即時解説
  - 模試：最後にまとめて採点
  - 復習：間違えた／禁忌を踏んだ「要復習」問題だけを再出題
- **成績の記録** ― 累計正答率・禁忌ヒット累計・要復習数をブラウザ（localStorage）に保存。
- **単一／複数選択** ― 「1つ選べ」「2つ選べ」に対応。
- **キーボード操作** ― 数字キーで選択、Enterで解答／次へ。
- **画像付き問題＋拡大表示** ― X線・心電図・写真・シェーマなどの画像を問題に添付できます。作成フォームから画像を選ぶだけで添付でき（大きい画像は自動で縮小してbrowserに保存）、画像をタップ／「拡大」ボタンで全画面表示にし、ピンチや＋−ボタン・ホイールで拡大、ドラッグで移動、ダブルタップで等倍⇔拡大ができます。Apple Pencilで画像の上に所見を書き込むこともできます。
- **選択肢への直接書き込み（Apple Pencil対応）** ― 問題の選択肢の上に○×や線を直接書き込めます。Apple Pencilならいつでも書け（ペンは描く／指・マウスはタップで解答を選ぶ、を自動で使い分け）、ペンが無くても「選択肢に書き込む」トグルで書き込めます。
- **手書きメモ（Apple Pencil対応）** ― 各問題の下にも手書きキャンバスを用意。Apple Pencilの筆圧に応じて線の太さが変わり、ペン使用中はタッチを無視するパームリジェクション付き。ペン／消しゴム・5色・太さ・元に戻す・全消しに対応し、書いた内容は問題ごとにブラウザへ保存されます（選択肢への書き込みも同様に問題ごとに保存）。キャンバス左下の大きなトグルボタン、またはキーボード **P/E** でペン⇄消しゴムを素早く切り替えられます。
- **アプリ内で問題を作成・編集** ― フォームから自作問題を追加でき、各選択肢に「正答」「禁忌」を指定できます。作った問題はブラウザに保存され、そのまま出題プールに合流します。
- **JSONで書き出し／読み込み** ― 自作問題をファイルに保存・共有・別端末へ移行できます（この環境は一時的なので、残したい問題は書き出しておくのが安全です）。

## 起動方法

ビルド不要の静的アプリです。リポジトリ直下で簡易サーバを立てて開きます。

```bash
# いずれか
npm start                 # → http://localhost:8080
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。

## 問題の追加・編集

### アプリ内で追加する（おすすめ）

スタート画面の「**＋ 自分の問題を作成・管理**」ボタンから、フォームで問題を作成できます。

- 各選択肢の右にある「**正**」（正答）／「**禁忌**」（選ぶと不合格級の禁忌肢）にチェックを付けます。
- 「複数選べ」を選ぶと、正答に指定した数だけ「◯つ選べ」として自動出題されます。
- 保存した問題はブラウザ（localStorage）に保存され、科目フィルタにも自動で追加されます。
- 「**一括貼り付け取り込み**」で、問題文・選択肢・正答をまとめて貼り付けて複数問を一度に追加できます（`科目:` `正答:` `禁忌:` `出典:` `解説:` `重要度:` の指定、a/1/①/ア などの選択肢記号、`---` または空行での問題区切りに対応）。厚労省の公開過去問など、手元にある問題を自分の学習用に取り込むのに便利です。取り込んだ問題は**この端末のブラウザ内にのみ保存**され、リポジトリには書き込まれません（私的利用向け）。
- 「**JSONで書き出し**」で自作問題をファイル保存、「**読み込み**」で取り込めます。バックアップや共有、別端末への移行に使えます。
- 「**iCloud/ファイルに保存**」（iPhone/iPad）… 共有シートから「"ファイル"に保存」→ iCloud Drive を選ぶと、問題（画像を含む）をiCloudに保存・他端末と共有できます。取り込みは「読み込み」から iCloud 上のファイルを選択します。
  - ※ 静的Webアプリのため iCloud への「自動同期」はできません（自動同期には純正アプリや専用サーバーが必要）。上記は共有シート経由の手動保存です。対応していないPCブラウザでは通常のダウンロードになります。
  - ※ 手書きメモ・選択肢への書き込みは各端末のブラウザ内に保存される一時データで、JSONには含まれません（問題本文・画像のみ書き出されます）。

### 組み込み問題を編集する（開発者向け）

組み込みの問題は `data/questions.js` の `window.QUESTIONS` 配列に定義されています。1問は次の構造です。

```js
{
  id: "cir-001",           // 一意なID
  subject: "循環器",        // 科目（フィルタ・集計に使用）
  topic: "気管支喘息と降圧薬",
  importance: 3,           // 3=必修級 / 2=頻出 / 1=標準
  type: "single",          // "single"（1つ選べ）/ "multiple"（複数選べ）
  pick: 2,                 // multiple のとき選ぶ数
  stem: "問題文…",
  image: "data:image/... または URL",  // 任意：X線・心電図・写真・シェーマ
  imageAlt: "画像の代替テキスト",         // 任意
  choices: [
    { text: "選択肢", correct: true,  forbidden: false, note: "選択肢の解説" },
    { text: "禁忌肢", correct: false, forbidden: true,  note: "なぜ禁忌か" }
  ],
  explanation: "全体解説",
  pearl: "覚えておく一言（禁忌のポイント等）"
}
```

- `forbidden: true` を付けた選択肢が「禁忌選択肢」として特別扱いされます。
- 新しい `subject` を追加すると、スタート画面の科目フィルタに自動で現れます。

## 注意

本アプリに収録している問題は**学習用に作成したオリジナルの練習問題**であり、実際の国家試験の過去問そのものではありません。医学的内容は一般的な標準治療に基づいていますが、診療・受験対策は必ず最新の成書・ガイドラインで確認してください。
